# Audio & Voice Direction

## Creative Goal
Make the access sequence feel technologically sophisticated and ceremonial, never like a video game.

Character: deep, clean, corporate, cinematic, restrained.

## Core Voice Line
“Access granted. Welcome to Command Center.”

Use a confident professional voice with light processing.

## Sequence
RESMIKAN click → UI click → PIN beeps → authentication tone → ACCESS GRANTED → short pause → “Access granted.” → short pause → “Welcome to Command Center.” → system activation ambience → cinematic transition → background music.

## Sound Effects
Recommended: UI click, PIN key beep, authentication scan, success confirmation, subtle error tone, transition whoosh, low cinematic impact.

Avoid arcade sounds, aggressive glitches, alarms, loud bass, and excessive effects.

## Mixing
Priority: voice, system cues, music, ambience. Reduce music during voice-over.

## Controls
Provide sound on/off and visual state. Persist preference during session. Make controls keyboard accessible.

## Browser Rules
Start audio only after explicit user gesture. Use RESMIKAN as the preferred gesture. Handle media play() failures.

## Missing Audio
Continue visually if audio cannot load. Never freeze the experience.

## Accessibility
Provide equivalent visual text for important voice content. Do not make critical event information audio-only.
